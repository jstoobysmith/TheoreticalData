# TheoreticalData

A database of open/solved problems/theorems/definitions from theoretical physics.

## Contributing

### Adding Definitions and Theorems

1. **Create a fork** of this repository
2. **Use a template file** - Take one of the template files (`Definitions.yml`, `Theorem.yml`, `Calculation.yml`)
3. **Fill in your content** - Complete the template with the definition, theorem, or calculation details
4. **Add to directory** - Place the filled template in the `./Data` directory
5. **Make a pull request** - Submit a pull request with your contribution
